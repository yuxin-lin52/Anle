# 01 词法结构

状态：已实现。

## 关键字

`add call fn val type fix give take outs if else for while in max match case unsafe pub sle ABI hide kill asm and or not null re fa int float bool str int_8 int_16 int_32 int_64 uint_8 uint_16 uint_32 uint_64 list map que stack`

## 符号

`= : ; ~ , . ( ) [ ] { } + - * / % < > ? & | ^ ! == != <= >= << >>`，以及标记 `#:`（块）、`##:`（模块）、`###:`（包）。

## 注释

整行 `//`——仅第 0 列，允许缩进，不支持行中注释。行内其余部分编译器忽略。

## 字面量

- 整数：十进制；`0x` 十六、`0b` 二、`0o` 八，支持下划线分段（`0b1111_0000`）。
- 浮点：小数点与科学计数法（`1e6`、`1.5e-3`）。
- 字符串：普通 `"…"` 支持 `\n \t \\ \"` 四转义——未知转义是编译错误；原样 `@"…"` 反斜杠原样、`""` 转义引号。字符串不跨行。
- 真假值：`re`（真）/ `fa`（假）。

## 源文件

UTF-8 无 BOM、LF 换行。一个 `.an` 文件是一个完整程序（或一个模块）。
