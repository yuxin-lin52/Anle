# 07 集合操作

状态：已实现。

## 规则

四种集合：`list`（有序）、`map`（键值）、`que`（先进先出）、`stack`（后进先出）。元素类型用圆括号：`list(int)`、`map(str, int)`。

| 操作 | 函数 | 适用 |
|---|---|---|
| 数量 | `len(x)`（str 按字符）/ `len_utf8`（字节） | 全部 |
| 末尾加入 / 取出 | `push` / `pop` | list、que、stack 共用 |
| 指定位置插入 / 删除 | `insert` / `remove` | list（remove 按 map 键删） |
| 清空 | `clear` | 全部 |
| 是否包含 | `has` | 全部 |
| 键 / 值 | `keys` / `vals` | map |
| 排序 / 查找位置 | `sort` / `index` | list |
| 判空 | `empty` | 全部 |
| 增改键值 | `put` | map |

- 取用走下标（`列表[1]`、`配置["超时"]`）；赋值直达（`列表[1] = 值`）。切片复用范围符：`列表[1~3]`、`串[2~4]`——1 基、含两端。
- 构造：list 与 map 有字面量（`[1, 2, 3]`、`{"超时": 30}`）；que/stack 用类型名构造（`que([1,2,3])`、`stack()`）；空 map 写 `map()`。
- 遍历：`for x in 集合:`；字符串按字符遍历。
- 嵌套规则：list/que/stack 的元素装容器是错误；map 的值、结构体字段装容器允许。原则：没名字的地方不套没名字的地方。拒绝时带改法：用键值表（`{"语文": [90, 85]}`）或结构体字段分组。
- `print` 输出与源码写法一致：`[1, 2, 3]`、`que[1, 2]`、`{"超时": 30}`、`点(3, 4)`——与构造语法相同，零新符号。
- 命名规则：语义随类型不同 ⇒ 名字写清类型（`len` 字符数 vs `len_utf8` 字节数；`read_8/16/32/64`）；同一动作跨类型复用 ⇒ 按实参分派（`str(x)` 收 int/float/bool）。

## 理由

- 内置函数式：不引入「方法」概念——自定义类型保持只有字段。
- 一套 `push`/`pop` 服务 list、que、stack：复用即省记忆。
- `put` 而非 `set`：`set` 与赋值 `=` 撞车。map 取用走下标，与 list 一致，学一次。
- map 字面量：`"名字": 值` 一眼可读。`{}` 内 `:` 是独立上下文，与块标记、`if …:` 位置互斥。
- 嵌套禁令：错配的槽宽曾静默损坏数据。现行规则响亮拒绝，报错写明分组改法。
- 输出即写法：`print` 显示的形态可以原样敲回成字面量——两个方向都零记忆。
