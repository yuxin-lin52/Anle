# 05 类型系统

状态：已实现。能力约束已设计，尚未实现。

## 能力约束

能力标注让泛型代码对类型参数使用运算符。声明写在参数表内：`add fn "大"(T <) (a T, b T) T = (a > b) ? a : b`。派生：`>` `>=` 由 `<` 派生、`!=` 由 `==` 派生。双点核对：定义点拒绝能力之外的运算（报错指定义行）；实例化点代入真实类型全量重查。落地前，类型参数的非结构操作一律拒绝。

## 规则

- 标量：`int`（i64）、`float`、`bool`、`str`。变量类型可推断；**函数参数与返回类型必写**。真假值 `re` / `fa`。
- 定长整数 `int_8/16/32/64`、`uint_8/16/32/64` 仅 unsafe 内可见。字面量自动收窄（`小 & 0x0F`）；变量需显式转换。安全层溢出报错；unsafe 允许绕回。
- 下标从 1 起：`列表[1]` 是第一个元素。与含两端的范围符一致——`for i in 1~长度` 走完整表，永远不存在「要不要减一」。切片（`列表[1~3]`、`串[2~4]`）复用同一符号。
- `null` 是唯一空值。只有显式声明可空的位置能装它，且使用前必须判断。字段链自动逐级判空（`head.next.值`）；悬空引用是带行号的运行时错误。
- 转换是类型名当函数：`int("5")`、`str(数字)`、`float(文本)`、`uint8(300)`。
- 积类型：`add type "点" = (x int, y int)`。类型名即构造器（`点(3, 4)`）；字段用 `.`。没有方法——操作走内置函数，自定义比较走比较器 fn。
- 把手 `类型*`：带星存 8 字节把手。赋值、传参、装容器照抄把手——全部指向同一对象。不带星是值拷贝。自引用与互指字段必须带星（裸环编译期拦截）。字段链自动解引用。`list(节点*)` 放开；map 键拒把手。
- 和类型：`add type "算式" = 数(int) | 加(算式*, 算式*)`。变体名即构造器。判别用 `match` + `case 变体(绑定)`（解构绑定），带编译期穷尽检查（新增变体暴露所有未更新的 match），`case _` 兜底。match 对象收「类型可推断的表达式」。
- 溢出：安全层整数溢出报错（常量溢出编译期拦，运行期溢出护栏带行号）；unsafe 允许绕回。
- 泛型：编译期单态化。`add type "对子"(A, B) = (首 A, 次 B)`；`add fn "换位"(A, B) (p 对子(A, B)) 对子(B, A)`——类型实参由调用点推出，每个用到的组合只展开一份。类型参数默认只许结构操作；算术需要能力标注（见「能力约束」节）。

## 理由

- 函数边界必写类型：函数是接口，写清类型让错误在调用处暴露。其余位置推断省略，保持零负担默认。
- 下标 1 基与含两端范围符、for 循环三点统一。下标、范围、循环共享一个起点——不存在「减一」决策。
- 显式把手：引用是语义选择，写在类型上才可见可查。不带星保持值语义。裸环被拒，迫使设计写明「这里是引用」。
- 和类型 + 穷尽 match：变体是封闭集合；新增变体会当场暴露所有未处理的 match。这是编译期保证，不是约定。
- payload 统一 8 字节槽：与容器槽铁律同构。裸 struct 禁入变体与容器——否则槽宽错配静默损坏数据。
- 单态化是唯一可行路线：类型擦除需要运行期盒子与虚表，与无运行时冲突。
- 显式转换：数字从哪来、是什么类型，写在明处。隐式提升把类型不一致从编译错误变成运行期意外。

## 显式不提供

- 方法——操作走内置函数；自定义类型只有字段
- 运算符重载——自定义比较走比较器 fn
- 自动装箱——递归字段必须写 `类型*`
- 嵌套容器 `list(list(int))`——「没名字的地方不套没名字的地方」；分组用 map 值或结构体字段
- 隐式数值提升
