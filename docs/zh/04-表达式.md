# 04 表达式

状态：已实现。

## 运算符

| 族 | 运算符 | 说明 |
|---|---|---|
| 算术 | `+ - * / %` | `int` 与 `float` 不显式转换不混算；安全层溢出报错 |
| 比较 | `== != < > <= >=` | 值比较；`==` 深入字符串、列表、map、结构体字段 |
| 逻辑 | `and` `or` `not` | 关键字；`and`/`or` 短路 |
| 位运算 | `& \| ^ << >> !` | 仅整数；`!` 是按位取反（`not` 是逻辑非）；`>>` 是算术右移 |
| 三元 | `条件 ? a : b` | 最低优先级、右结合、惰性——未选中分支一条指令不执行 |

优先级：比较 `< | < ^ < & < 移位 < 加减 < 乘除`。

## 调用与读取

- `call val "名"` 读值；`call fn "f"(x)` 调函数。
- 字段访问：`位置.x`；链式自动解引用把手并逐级判空（`head.next.值`）。
- 下标：`列表[1]`、`配置["超时"]`——1 基，与含两端范围符一致。
- 切片：`列表[1~3]`、`串[2~4]`——1 基含两端，复用范围符。

## 转换

类型名当函数：`int("5")`、`str(数字)`、`float(文本)`、`uint8(300)`。没有隐式转换——`int` 与 `float` 不显式转换不混算，数字从哪来、是什么类型写在明处。

## 理由

- 惰性三元：它是公式递归的唯一出口——急切求值下表达式里的递归调用会无限展开。
- 链式比较不做：解析复杂度超过用例；写 `and`。
- 显式转换：隐式提升把类型不一致从编译错误变成运行期意外。
- `!` 按位取反、`not` 逻辑非：`~` 已是范围符，`!` 语义空闲，两者都眼熟。
